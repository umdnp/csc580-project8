# Abstract

AI coding agents can use reusable instruction packages, called *agent skills*, to carry out specialized tasks. Reusing a skill saves effort but can also introduce changes to commands, scripts, external dependencies, and other security-sensitive instructions. GitSkills is a large collection of agent-skill files found in public GitHub repositories. Its many repeated and related skills make it useful for studying changes associated with reuse. We investigated whether related skills in this dataset contain security-sensitive behavior absent from an earlier observed artifact. Our static-analysis pipeline identifies related skill content, infers plausible comparison direction from available evidence, compares changed operations, and evaluates those changes against eleven defined risk indicators. The indicators identify changes worth reviewing, not confirmed vulnerabilities.

We analyzed **three non-overlapping, stratified random samples totaling 300 skill families**, using 6,570 artifacts and 2,157 selected primary directed comparisons. The automated scanner identified supported indicators in **63 families (21.0%)** and **340 comparisons (15.8%)**. Local script execution and external code-acquisition changes appeared across the most families. Comparison-level rates varied much more across trials, largely because a few families contributed many related comparisons; a sensitivity calculation excluding each trial's largest contributor reduced the combined pair-level rate to 8.4%, while the family-level rate remained 20.2%. These sample percentages do not estimate prevalence across all GitSkills. Some comparison directions and supporting-file content remain uncertain, and independent human validation is in progress. The study provides reproducible evidence of candidate security-sensitive changes while distinguishing observed differences from verified historical or security outcomes.
