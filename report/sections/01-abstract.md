# Abstract

Agent skills can be copied and adapted while retaining familiar descriptions, even when their instructions change. The group investigated whether modified or reused skills introduce security-sensitive behavior absent from an earlier or source artifact. The pipeline groups GitSkills occurrences into candidate families, identifies related content, records evidence for comparison direction, and evaluates changed static evidence against eleven defined risk indicators. These indicators cover specific changes involving executable downloads, network destinations, dependencies, destructive operations, credentials, permissions, sensitive paths, local scripts, and external instructions. They are review signals rather than confirmed vulnerabilities.

The saved exploratory run contains 1,151 artifacts from 30 provisional families and 3,997 directed comparisons. The assessor reports at least one supported indicator in 588 comparisons (14.7%); 206 comparisons have incomplete evidence coverage. Local script execution, network expansion, and credential-related changes are the most frequently reported categories. Additional graph edges account for most comparisons, and repeated artifacts make observations dependent. The selected families are not a representative sample of GitSkills. Independent review and adjudication for this run remain pending, so these counts measure automated findings rather than validated security incidents or scanner accuracy. The study provides evidence of candidate security-sensitive changes and an auditable way to examine them, while leaving their validated frequency and historical lineage unresolved.
