# Validation data

This folder preserves **historical Sprint 1 validation material**. Its `archive/`
subfolder contains the former fixed 13-pair sample. These files are not inputs
to the final Sprint 3 research results.

The current [Manual Annotation Protocol](../../docs/instructions/manual_annotation_protocol.md)
describes the review fields and adjudication procedure. Active Sprint 3 review
samples, original independent annotations, adjudicated decisions, and computed
validation summaries are stored separately under:

- [`notebooks/end_to_end_pipeline/sprint3/results1/`](../../notebooks/end_to_end_pipeline/sprint3/results1/)
- [`notebooks/end_to_end_pipeline/sprint3/results2/`](../../notebooks/end_to_end_pipeline/sprint3/results2/)
- [`notebooks/end_to_end_pipeline/sprint3/results3/`](../../notebooks/end_to_end_pipeline/sprint3/results3/)

All **90 directed** and **45 relationship** Sprint 3 cases have completed team
adjudication; see the [reproducibility guide](../../docs/instructions/reproducibility.md)
and [Appendix C](../../report/appendices/C-validation-materials.md) for the
final validation totals and their interpretation.
