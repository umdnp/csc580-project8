# Validation data

Active validation samples and reviewer templates are generated by `summarize_scans`
under `results/review/`. Follow the [Manual Validation Protocol](../../docs/validation/validation_protocol.md)
to conduct independent reviews and produce adjudicated CSVs for metrics.

The `archive/` folder retains the former fixed 13-pair Sprint 1 sample. It is
historical evidence and is not an input to the current reporting workflow.
